# Karaokê Mundo

Karaokê recreativo para navegador, com repertório brasileiro e internacional via player oficial do YouTube, pontuação divertida e microfone remoto no celular. Projeto inicial em implementação.

O site não armazena áudio ou músicas: apenas incorpora vídeos públicos que permitem reprodução externa. A pontuação não compara a melodia original; calcula indicadores de voz captada pelo microfone.
